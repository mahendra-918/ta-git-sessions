# Git & GitHub Workshop Agenda (2-Week Plan)

---

### **Week 1: Solo Developer Fundamentals**

* **Session 1: Intro to Version Control & Your First Commit**
    * Topics: What is Git?, Git vs. GitHub, `git config`
    * Core Commands: `clone`, `add`, `commit`, `push`

* **Session 2: Branching and Merging Basics**
    * Topics: Why we use branches, isolating work
    * Core Commands: `branch`, `checkout`, `merge`

---

### **Week 2: Collaboration & Real-World Skills**

* **Session 3: Working with Remote Repositories**
    * Topics: Syncing local and remote code
    * Core Commands: `pull`, `push`, `remote -v`

* **Session 4: Collaboration with Forks & Pull Requests**
    * Topics: The open-source workflow
    * Core Concepts: Forking, creating a Pull Request (PR), code review

---
